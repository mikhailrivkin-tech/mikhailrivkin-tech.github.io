BB Google Calendar Integration

A personal Google Calendar connection for a private BB workspace on the account owner's server.

What the integration does

The integration uses Google OAuth 2.0 and the Google Calendar API to synchronize the owner's calendar events between a Google account and the BB application. It can retrieve calendar event details, display locally synchronized events in BB, and create, change or delete events in Google Calendar when the owner invokes those features.

How data is used

Calendar data is used solely for the owner's calendar management and synchronization. OAuth credentials are kept in the private BB server configuration, not on this public information site. The integration is not a general public calendar service.

Privacy and access

Review the Privacy Policy to learn what Google Calendar data is accessed, stored and shared, and how the owner can revoke Google access. This page itself does not request access to Google Calendar and does not accept calendar data.

Contact

Questions about this information site may be submitted through the public GitHub issue tracker. Do not share private calendar data, passwords or authorization tokens in public issues.
